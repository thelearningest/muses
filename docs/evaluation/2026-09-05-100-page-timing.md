# 100-page production-build timing

Fresh local compiled-Worker run `34deb9ae-d20c-4fda-b55e-96e9eff274c3` completed in **96.5884 seconds** on September 5, 2026 (Singapore time). This is a local timing pass, not yet a hosted production timing claim.

The fixture contains the first 100 unchanged PDF pages of the supplied 109-page scanned book (37,283,313 bytes). The timer starts before job creation, fingerprinting, and upload; it ends when the complete validated game is saved. Loading the test fixture into the browser precedes the timer. Actual browser rendering/client, compiled Worker, local D1/R2, and paid OpenAI requests are used. No extraction responses were seeded or reused across jobs. Provider-side prompt caching can benefit repeated source input.

No partial output is accepted and uncertain provider calls still require explicit retry.

Hosted timing and live Turnstile behavior still need verification after deployment.

Production configuration check: Turnstile and the full hosted pipeline were exercised with the same 100-page fixture. The first hosted job initially paused on an obsolete OpenAI key (HTTP 401, rejected before charge), then resumed after the working key was stored as a secret and produced **The Shifting Lattice**, a nine-quest RPG. Hosted traces then identified three-at-a-time page upload as the remaining throughput bottleneck; the browser limit was raised to eight bounded 384 KiB page preparations before the next fresh timing run.
